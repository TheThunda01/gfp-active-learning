GFP case study

What did the first shortlist leave out?

Two rules started with the same 64 archived green fluorescent protein (GFP) measurements. One chose 64 more records from the full pool. The combined rule first narrowed the pool from 2,336 records to 256. Of the 64 records chosen by diversity alone, 4–15 remained eligible after screening across the four runs. The two rules ultimately chose 3–8 of the same records per run.

The first 64 choices

“Eligible” counts the full-pool choices that survived the screen. “Chosen by both” counts the records both rules actually selected.

After this batch, each rule had 128 labels. We measure prediction error in log-brightness units using root mean squared error (RMSE). The gap is combined RMSE minus diversity-only RMSE. Positive values mean the combined rule had higher error.
