# Scientific data attribution

The measured GFP records in `data/dataset.csv` are adapted from:

Sarkisyan KS et al. **Local fitness landscape of the green fluorescent protein.** *Nature* 533, 397–401 (2016). [doi:10.1038/nature17995](https://doi.org/10.1038/nature17995).

Original data: **Local fitness landscape of the green fluorescent protein**, Figshare, version 1, [doi:10.6084/m9.figshare.3102154.v1](https://doi.org/10.6084/m9.figshare.3102154.v1). The archive lists **Creative Commons Attribution 4.0 International (CC BY 4.0)**. See the [license terms](https://creativecommons.org/licenses/by/4.0/) and [legal code](https://creativecommons.org/licenses/by/4.0/legalcode). Attribution is retained here; no endorsement by the original authors is implied.

Changes: a deterministic 3,600-record subset was selected; full-length measured sequences and original median log-brightness values were matched to the TAPE derivative; new record identifiers, source-line references, checksums, roles, and analysis outputs were added. Shorter TAPE sequence strings were excluded. The original labels were not rescaled or fabricated.

TAPE supplied derivative sequence records and train/validation/test membership: Rao R et al. **Evaluating Protein Transfer Learning with TAPE.** *NeurIPS* 32 (2019). [Paper](https://proceedings.neurips.cc/paper/2019/hash/37f65c068b7723cd7809ee2d31d7861c-Abstract.html), [official repository](https://github.com/songlab-cal/tape). Its software license is distinct from the original scientific-data license; this repository does not relicense the data under MIT or copy TAPE software.

The `LICENSE` file applies to this project's original code and documentation. It does not replace these data rights. Figures and tables generated here summarize the attributed data and should retain this provenance when reused.
