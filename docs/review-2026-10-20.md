# Scientific and editorial review — 20 October 2026

This review covered the README, authored guides, data and license notices, the four-policy ablation, saved reports, reference lists and search records. Code, configuration and output tables were inspected where they define a documentation claim. This is an editorial and source-verification pass, not a new experiment or a claim of comprehensive literature coverage.

## Source coverage

The [reference audit](reference-audit.json) contains 12 source records: six research papers, one dataset and five software/documentation resources. Publication metadata were checked through PubMed or official proceedings; available passages were checked for the actual claims used. Full PMC bodies were retrieved for Sarkisyan and Greenman. Relevant full-text sections were retrieved for Balleza and Luo. Parkinson remained abstract-only. TAPE’s official abstract and repository were available, but its paper PDF timed out during this check; exact local split claims were also checked against the data and preparation code.

Figshare’s version-specific API confirmed the original dataset identifier, file identity and CC BY 4.0 license. Official TAPE and Protein UQ READMEs were checked; their model implementations were neither executed nor copied. The audit records these access limits instead of implying that every source was reviewed in full. No external paper’s performance estimate is presented as a result of this project.

## Remaining limits

The saved results describe one related GFP sequence subset with four computational seeds. Tree spread is not calibrated uncertainty, and the source readout does not identify which molecular mechanism produced a change in fluorescence. No new blind evaluation or prospective experiment was conducted. Frozen result reports, the hashed data README and the original plan were reviewed but preserved; their historical formatting is not silently rewritten. These checks improve clarity and traceability without claiming that every possible error has been eliminated.
