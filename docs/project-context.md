# What this project is trying to show

A dataset can contain thousands of measurements while a real project can afford only a small next batch. Choosing those observations is a different problem from fitting a model once to a complete table. This repository makes that distinction visible without proposing new proteins or asking anyone to run experiments.

The biological setting is a public, measured green fluorescent protein landscape. Green fluorescent protein (GFP) produces a useful fluorescent signal, but the reported cellular brightness reflects several processes: expression (protein production), folding (adopting a three-dimensional structure), and maturation of the chromophore (the light-emitting group). It should not be treated as a universal measurement of protein quality. The [original study](https://doi.org/10.1038/nature17995) supplies the observations; this project supplies a small, auditable computational experiment.

The program starts with a few revealed labels—stored measurements—from a fixed pool of candidate observations. It compares choosing additional records uniformly at random with choosing records through model disagreement and sequence diversity. Both policies share their initial observations and label budgets. Two separate evaluation sets ask whether learning is useful for nearby sequences and for a more mutated part of the same landscape.

The key result is deliberately mixed. In the included run, the heuristic has a slightly lower average error locally but a slightly higher average error on the more mutated set. That contrast is more informative than presenting one favorable curve as a general win. The [2025 Protein UQ study](https://doi.org/10.1371/journal.pcbi.1012639) provides a broader reason to evaluate acquisition rather than assuming uncertainty scores will help.

For a reader assessing the repository, the main themes are reproducible data handling, sequence-aware evaluation, a testable label-access boundary, repeated comparisons, and clear limits on biological interpretation. All records were already measured; repeating the simulation does not produce biological replication. The public evaluation metrics are now observed, so future changes guided by them are benchmark development rather than fresh confirmation.

The [glossary](glossary.md) defines the terms and the [assumptions](assumptions.md) explain the design choices. Read the [biology guide](biology-and-concepts.md) for the conceptual background, [methods](methods.md) for exact choices, and [provenance](data-provenance.md) to trace the original data. The project is intended to demonstrate careful computational practice, not a validated strategy for a laboratory campaign.
